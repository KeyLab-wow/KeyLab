# Contributing to KeyLab

Thank you for your interest in contributing to KeyLab!

KeyLab is a personal Mythic+ journal focused on helping players learn from their own gameplay, experiment with builds and stats, and track long-term improvement.

## Before Contributing

Please keep the project's core philosophy in mind:

KeyLab is intended to be:

* Personal and reflective
* Focused on self-improvement
* Supportive of experimentation
* Friendly to casual and competitive players alike
* Local/private-first

KeyLab is **not** intended to be:

* A combat meter replacement
* A Warcraft Logs replacement
* A leaderboard or ranking system
* A player rating or blacklist tool
* A recruitment or performance-scoring addon

## Reporting Bugs

If you encounter a bug, please open a GitHub Issue and include:

* KeyLab version
* World of Warcraft version
* Steps to reproduce the issue
* Any Lua errors
* Screenshots if applicable

The more information provided, the easier it is to investigate.

## Suggesting Features

Feature requests are welcome.

When suggesting a feature, please explain:

* The problem you are trying to solve
* How the feature would help players
* How it fits within KeyLab's goals

Not every suggestion will be implemented, but all feedback is appreciated.

## Pull Requests

Pull requests are welcome for:

* Bug fixes
* Performance improvements
* UI improvements
* Documentation updates
* Quality-of-life features

Please try to keep changes focused and easy to review.

## Design Philosophy

Whenever possible, KeyLab should help players answer questions such as:

* What builds work best for me?
* What stat profiles produce my best results?
* Am I improving over time?
* What gear should I target next?

The addon should avoid encouraging toxicity, player shaming, or public ranking systems.

## Thank You

Whether you report a bug, suggest a feature, submit code, or simply use the addon, thank you for helping improve KeyLab.
