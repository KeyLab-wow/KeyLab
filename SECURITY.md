# Security Policy

## Supported Versions

Security and bug fixes are generally provided for the most recent public release of KeyLab.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.1   | :white_check_mark: |
| 1.1.0   | :x:                |

## Reporting a Vulnerability

Users are encouraged to update to the latest available version through CurseForge.

If you discover a security issue, vulnerability, or unexpected behavior that could affect users of KeyLab, please report it through the project's GitHub Issues page.

When reporting an issue, please include:

- A description of the problem  
- Steps to reproduce the issue  
- The KeyLab version being used  
- World of Warcraft version/build information  
- Any relevant screenshots or error messages  

Reports will be reviewed as time permits. If the issue is confirmed, a fix will be included in a future release and documented in the project changelog.
